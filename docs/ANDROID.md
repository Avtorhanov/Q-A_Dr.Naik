# Приложение для Android

Android-приложение — это окно, в котором работает та же страница, что и на сайте. База и интерфейс лежат внутри APK, из сети приходят только видео, аудио и шрифты.

## Как получить APK

1. Отправьте изменения в ветку `main` на GitHub.
2. Откройте вкладку **Actions**. Сборка «Android APK» идёт около пяти минут.
3. Откройте раздел **Releases** на странице репозитория, скачайте `zakir-naik-qa.apk` и откройте файл на телефоне. Android попросит разрешить установку из этого источника.

Сборку можно запустить и вручную: Actions → Android APK → Run workflow.

Каждая отправка изменений в приложении или базе собирает новый выпуск. Он ставится поверх предыдущего, потому что подписан тем же ключом.

## Что внутри

- `android/app/src/main/java/.../MainActivity.java` — единственный экран.
- Страница открывается с адреса `https://appassets.androidplatform.net/`. Файлы при этом берутся из APK. Такой адрес нужен, чтобы YouTube, Rutube и OK разрешили встроенный плеер.
- Ссылки «в источнике» открываются в браузере или в приложении источника.
- Видео разворачивается на весь экран, кнопка «Назад» сворачивает его обратно.
- Системные панели окрашиваются под выбранную тему.
- Требуется Android 7.0 или новее.

## Ключ подписи

`android/demo.keystore` — демонстрационный ключ, он открыто лежит в репозитории. Для магазина приложений нужен собственный ключ, который хранится в секретах GitHub, и разрешение правообладателя на материалы.

## Сборка на своём компьютере

Нужны JDK 17, Android SDK (платформа 34) и Gradle 8.9:

```
cd android
gradle assembleDebug
```

Готовый файл: `android/app/build/outputs/apk/debug/app-debug.apk`.

## Что не проверено

Сборка настроена, но в этой версии ещё ни разу не запускалась: первый запуск произойдёт после отправки кода на GitHub. Если сборка упадёт, текст ошибки будет во вкладке Actions.
