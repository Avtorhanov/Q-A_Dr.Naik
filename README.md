# Вопрос — ответ: поиск по Q&A Закира Найка

Неофициальный указатель. Человек пишет вопрос, приложение находит такой же вопрос из реальных выступлений Закира Найка и показывает ответ в источнике: видео с нужной минуты, аудио, текст сессии или страницу книги. Приложение ничего не сочиняет и не пересказывает.

В базе 232 вопроса: 72 с ответом на русском, 160 на английском. Вручную не сверен ни один (`verified: false`).

## Что нового в версии 2

- Три темы оформления: светлая, тёмно-синяя и изумрудная, плюс «как в системе».
- Плавные раскрытия и переходы; тени у вкладок в светлой теме, свечение и объём в тёмных.
- Встроенный плеер: ролики YouTube, Rutube и OK играют прямо в карточке, с минуты вопроса. Аудио и видео по прямой ссылке (`media_url`) тоже играют здесь.
- Читалка текста ответа со строкой источника (только при `rights: granted` или во внутреннем тесте).
- 35 новых записей.
- Android-приложение, которое собирается на GitHub автоматически.

## Как посмотреть

| Способ | Что сделать |
|---|---|
| Сайт | Settings → Pages → Source: «Deploy from a branch», ветка `main`, папка `/ (root)`. Через пару минут сайт откроется по адресу `https://<имя>.github.io/<репозиторий>/` |
| Android | Раздел Releases → `zakir-naik-qa.apk`. Подробности: [docs/ANDROID.md](docs/ANDROID.md) |
| Один файл | `standalone.html` открывается без сайта. Плеер в нём работает, только если файл открыт по адресу `http(s)://`, а не с диска |

## Команды

```
python3 tools/validate.py     # проверить базу
node tests/search.test.js     # проверить поиск
python3 tools/build.py        # пересобрать standalone.html
python3 -m http.server 8000   # открыть сайт у себя: http://localhost:8000
```

## Принципы

1. Никакой генерации ответов: только существующий ответ из источника.
2. У каждого ответа есть источник: название, дата, ссылка, по возможности таймкод.
3. Нет прямого ответа — приложение так и говорит и показывает близкие вопросы.
4. Модель не дообучается. Поиск сравнивает вопрос с вопросами в базе.
5. Права принадлежат правообладателям. Без их разрешения тексты ответов не публикуются. См. [NOTICE.md](NOTICE.md).
