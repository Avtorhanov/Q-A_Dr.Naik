# Вопрос — ответ: поиск по Q&A Закира Найка

https://avtorhanov.github.io/Q-A_Dr.Naik/

Неофициальный указатель. Человек пишет вопрос, приложение находит такой же вопрос из реальных выступлений Закира Найка и показывает ответ в источнике: видео с нужной минуты, аудио, текст сессии или страницу книги. Приложение ничего не сочиняет и не пересказывает.

В базе 433 вопроса: 86 с ответом на русском, 347 на английском. Вручную не сверен ни один (`verified: false`). Последнее пополнение — 26.11.2026: дата видна в шапке приложения и задаётся в `app.js` (`dataVersion`).

## Выключатели функций

В начале файла `app.js` есть блок `FEATURES`:

| Выключатель | Сейчас | Что делает |
|---|---|---|
| `player` | `true` | Кнопки «Смотреть здесь» и «Слушать здесь»: запись играет в карточке с сайта источника |
| `reader` | `false` | Кнопка «Читать здесь» и загрузка `private_texts.json`. Включать после разрешения правообладателя |

При `false` приложение показывает только ссылки на источник. Код функций при этом остаётся в файле.

## Команды

```
python3 tools/validate.py     # проверить базу
node tests/search.test.js     # проверить поиск
python3 tools/build.py        # пересобрать standalone.html
python3 -m http.server 8000   # открыть сайт у себя: http://localhost:8000
```

## Принципы

1. Никакой генерации ответов: только существующий ответ из источника.
2. У каждого ответа есть источник: название, дата, ссылка, по возможности таймкод.
3. Нет прямого ответа — приложение так и говорит и показывает близкие вопросы.
4. Модель не дообучается. Поиск сравнивает вопрос с вопросами в базе.
5. Права принадлежат правообладателям. Без их разрешения тексты ответов не публикуются. См. [NOTICE.md](NOTICE.md).
